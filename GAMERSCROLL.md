# GamerScroll

Game industry data crawling and daily report site. https://gamerscroll.com
AIScroll (tech/AI blog) shares this repo. https://aiscroll.io

## Build
- GamerScroll: `node generate-html-report.js` (full crawl) / `-q` (cache, 5 sec)
- AIScroll: `node generate-ai-blog.js` (generates `ai-docs/`)
- AIScroll translate: `node translate-ai-blog.js`
- Deploy: GamerScroll -> `docs/`, AIScroll -> `ai-docs/`, both via GitHub Pages.
- Never edit `docs/` or `ai-docs/` locally — auto-generated by GitHub Actions.

### Common Fields
- `slug`: English, kebab-case, 3-5 words
- `status`: `draft` -> `approved` (build publishes approved only)
- `date`: `YYYY-MM-DDTHH:MM` (30-min intervals). Empty = auto-fill on build.
- `title`: core keyword first, under 50 chars
- `summary`: 120-150 chars
- `keywords`: SEO keywords, mix main + long-tail
- `sources`: min 4-5. Never Namuwiki. AI articles: international sources only.
- `relatedDocs`: `["issue:slug", "wiki:cat/slug", "tech:cat/slug", "hotpick:slug"]` (max 4)

## Writing Style
- Open with 2-3 sentences (key facts), no heading.
- 4-7 sections: heading -> image -> 2-3 paragraphs each.
- Last heading: unique closing title (never "마치며"). Separator: `:` only.
- Tone: blog-style, conversational. Always name specific games/companies/numbers.
- Images: every 2-3 sections, 3-4 total. Landscape preferred. No thumbnail/body overlap.
- After drafting: share full text for review, not just JSON.

## AIScroll Translation
- English co-writing: add `keywordsEn`, `titleEn`, `summaryEn`, `contentEn`, set `needTranslate: false`
- `keywordsEn` is NOT auto-translated — always add manually.
- Auto-translate: `aitranslate.yml` workflow detects `needTranslate !== false`

## Daily AI Insight
Agent team workflow:
1. Explorer reads `data-cache.json` + recent 7 days
2. WebSearchers search today's news (48h rule)
3. Worker generates insight JSON (`reports/{date}.json`)
4. WebSearcher fact-checks + finds thumbnails
5. Worker merges corrections
6. Utility runs `fetchStockPrices()` for stock data
7. Quick build + commit/push
