클로드, 대화 속 인터랙티브 시각화 자동 생성 기능 출시: 100만 토큰 컨텍스트도 기본 제공

Editor JAI2026년 3월 14일

앤트로픽이 이틀 연속 대형 업데이트를 발표했다. 3월 12일 대화 속 인터랙티브 차트와 다이어그램을 자동 생성하는 '시각적 응답(Visual Responses)' 기능, 3월 13일에는 100만 토큰 컨텍스트 윈도우의 정식 출시(GA)를 공개하며 AI 어시스턴트의 새로운 기준을 제시하고 있다.

앤트로픽이 이틀 연속으로 대형 업데이트를 쏟아냈다. 3월 12일, 클로드가 대화 중에 인터랙티브 차트와 다이어그램을 직접 생성하는 '시각적 응답(Visual Responses)' 기능을 공개했다. 바로 다음 날인 3월 13일에는 100만 토큰 컨텍스트 윈도우를 표준 가격 그대로 정식 출시(GA)했다. 두 업데이트를 합치면, AI 어시스턴트가 '기본으로 할 수 있는 것'의 기준이 한 단계 올라간 셈이다.

인터랙티브 시각적 응답: 대화 속에서 태어나는 차트

새로운 '시각적 응답' 기능은 클로드가 대화 중 인터랙티브 차트, 아이디어 맵, 구조 다이어그램, 주기율표, 복리 이자 곡선, 타임라인 등을 인라인으로 자동 생성한다. 이미지 생성과 달리 HTML과 SVG 기반이라 클릭하고 조작할 수 있는 인터랙티브 요소다.

클로드가 시각화가 도움이 될 것으로 판단하면 자동으로 생성하며, 사용자가 직접 요청할 수도 있다. 3월 12일 베타로 출시됐으며 무료 플랜 포함 모든 사용자에게 기본 활성화된 상태다.

시각적 응답 vs. Artifacts: 무엇이 다른가

클로드에는 이미 아티팩트라는 사이드 패널 도구가 있다. 독립적인 코드, 문서, 인터랙티브 컴포넌트를 만들어주는 기능이다. 시각적 응답은 근본적으로 다른 목적을 가진다. 아티팩트는 영구적이고 별도 패널에 존재하며 재사용 가능한 산출물을 위한 것이다. 시각적 응답은 임시적이고 대화 흐름에 자연스럽게 녹아든다.

아티팩트를 '작업대'라고 생각하면, 시각적 응답은 '설명을 돕는 삽화'에 가깝다. 복리 이자를 설명해달라고 하면 답변 안에 인터랙티브 곡선이 바로 나타난다. React 컴포넌트를 만들어달라고 하면 그건 여전히 아티팩트로 간다.

100만 토큰 컨텍스트 GA: 표준 가격, 베타 헤더 불필요

3월 13일, 앤트로픽은 100만(1M) 토큰 컨텍스트를 정식 출시(GA)했다. 핵심은 가격이다. 오퍼스 4.6이 백만 토큰당 입력 $5/출력 $25, 소넷 4.6이 $3/$15인데, 9K 토큰을 보내든 900K 토큰을 보내든 동일한 단가가 적용된다. 프리미엄 추가 요금 없이, 베타 헤더도 필요 없다. 200K 토큰을 초과하는 요청은 자동으로 처리된다.

미디어 처리 용량도 크게 확대됐다. 요청당 이미지/PDF를 최대 600개까지 처리할 수 있으며, 이전 제한인 100개에서 6배 늘어났다. 벤치마크 결과도 인상적이다. 장문 컨텍스트 검색 벤치마크인 MRCR v2에서 클로드는 78.3%로 프론티어 모델 중 최고 점수를 기록했다. 8-needle 100만 토큰 테스트에서는 오퍼스 4.6이 76%로, 소넷 4.5의 18.5%를 압도했다.

Claude Code 통합: 100만 토큰이 기본값

Claude Code v2.1.75부터 Max, Team, Enterprise 플랜에서 100만 토큰 컨텍스트가 기본값이 됐다. 개발자에게 이는 전체 코드베이스, 방대한 문서 세트, 복잡한 멀티파일 프로젝트를 컨텍스트 제한 걱정 없이 처리할 수 있다는 의미다.

코딩 에이전트 평가의 기준인 SWE-bench Verified에서 오퍼스 4.6(Thinking 모드)은 79.20%로 1위를 차지했다. 방대한 컨텍스트와 벤치마크 최고 수준의 코딩 성능이 결합되면서, Claude Code는 AI 기반 개발 도구 분야에서 강력한 경쟁력을 갖추게 됐다.

경쟁 구도: 시각화 군비 경쟁의 시작

클로드의 시각적 응답 기능은 치열한 경쟁 속에서 등장했다. OpenAI의 ChatGPT도 유사한 인라인 시각화 기능을 출시했고, 구글의 제미나이도 자체 멀티모달 기능을 계속 확장하고 있다. AI 어시스턴트를 시각적으로 더 풍부하게 만들려는 경쟁이 업계 전반에서 가속화되고 있다.

다만 앤트로픽의 100만 토큰 가격 정책은 다른 종류의 경쟁 압력을 만들어낸다. API에서는 9K 토큰이든 900K 토큰이든 동일한 표준 단가가 적용되며 추가 요금이 없다. Claude Code에서는 Max($100~$200/월), Team, Enterprise 플랜에서 기본값으로 제공되지만, Pro 플랜은 지원 대상이 아니다. 사실상 프리미엄 구독 티어에서의 기본 제공이지만, API 레벨에서 토큰당 추가 비용 없이 100만 토큰을 처리할 수 있다는 점은 경쟁사 대비 명확한 가격 우위다.

새로운 기본값의 탄생

이틀 연속 쏟아진 두 업데이트는 앤트로픽이 AI 어시스턴트의 '기본값'을 재정의하려는 의도를 보여준다. 인터랙티브 시각화는 사용자가 새로운 도구를 배울 필요 없이 클로드의 응답을 더 풍부하게 만든다. API 추가 요금 없는 100만 토큰 컨텍스트는 대규모 코드베이스나 문서 작업에서 주요 마찰 지점을 크게 낮춘다.

시각적 응답이 데스크톱 전용이라는 제한과 베타 라벨은 아직 다듬을 부분이 남아있음을 시사한다. 그러나 방향은 명확하다. 앤트로픽은 AI 채택의 다음 물결이 강력한 기능을 '힘들이지 않고 기본으로 쓸 수 있게' 만드는 데 달려 있다고 판단하고 있다.
