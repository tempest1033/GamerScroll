딥마인드의 가장 바쁜 하루

AI2026년 2월 12일

2026년 2월 11일, 구글 딥마인드가 수학 난제를 푸는 연구 에이전트 '알레테이아'를 발표했다. 같은 날 프리뷰 중인 제미나이 3 옆에서 3.1 프리뷰까지 포착됐다. 하루에 이것저것 다 쏟아낸 딥마인드의 2월 11일을 정리한다.

2026년 2월 11일, 구글 딥마인드에게 바쁜 하루였다. 오전에는 미해결 수학 문제 13개를 풀어낸 AI 연구 에이전트 '알레테이아'를 발표했다. 같은 시간, 벤치마크 플랫폼에서는 '제미나이 3.1 프로 프리뷰'가 포착됐다. 제미나이 3 프로가 아직 정식 출시(GA)도 안 된 프리뷰 상태인데, 벌써 다음 세대가 모습을 드러낸 것이다. 수학 연구 전용 에이전트에, 아직 나오지도 않은 모델 두 세대가 한꺼번에. 꽤 바쁜 하루였다.

1. 알레테이아: 미해결 수학 문제를 푸는 AI

알레테이아(Aletheia)는 단순한 언어 모델이 아니다. 제미나이의 딥씽크(Deep Think) 모드 위에 구축된 다단계 연구 에이전트 시스템으로, 인간 수학자들이 수십 년간 풀지 못한 문제에 도전하도록 설계됐다.

시스템은 실제 수학자의 연구 과정을 모방한 세 단계 파이프라인으로 작동한다. 먼저 생성기(Generator)가 문제 공간을 탐색하며 후보 가설을 만든다. 이어서 검증기(Verifier)가 각 가설을 형식 논리에 따라 검증하고, 결함 있는 추론을 걸러내며 유망한 증명 경로를 찾는다. 마지막으로 수정기(Reviser)가 검증된 부분 결과를 받아 반복적으로 다듬는다. 약한 논증을 강화하고 논리적 빈틈을 메워, 완전한 증명이 나올 때까지 개선하는 것이다. 하나의 문제에 대해 이 순환이 수십 번 반복되기도 하며, 시스템은 실패한 시도에서도 학습한다.

목표는 폴 에르되시가 남긴 미해결 문제 700개였다. 에르되시는 겉보기에 단순하지만 실제로는 극도로 어려운 추측을 남기기로 유명한 20세기 수학자다. 알레테이아는 이 중 13개를 해결했다. 5개는 완전히 자율적으로 풀었다. 인간의 가이드 없이 시스템이 새로운 증명을 찾아낸 것이다. 나머지 8개는 기존 논문에 묻혀 있던 해법을 발굴했다.

IMO-ProofBench Advanced(국제수학올림피아드 수준의 증명 생성 벤치마크)에서는 91.9%를 기록했다. 수학계에서 수년은 더 걸릴 것으로 예상했던 수치다.

프로젝트 팀에는 한국인 연구자 김상현 교수가 참여하고 있다. 김 교수는 "내가 개념적 방향에 집중하는 동안 수천 개의 증명 경로를 지치지 않고 탐색해주는 동료가 생긴 것 같았다"고 소감을 전했다. 딥마인드는 이 시스템을 수학을 넘어 물리학, 컴퓨터 과학 등으로 확장할 계획이라고 밝혔다.

연구팀의 메시지는 "AI는 대체가 아닌 가속기"라는 것이다. 조합론적 반복 작업은 AI가 맡고, 창의적 직관과 방향 설정은 인간이 한다는 구도다. 물론 OpenAI의 GPT Pro도 이미 과학 연구에 널리 쓰이고 있어 이 분야가 딥마인드만의 영역은 아니지만, 미해결 문제를 자율적으로 풀어내는 전용 에이전트 시스템이라는 점에서 접근 방식이 다르다.

2. 제미나이 3 프리뷰: 이미 1위, GA는 얼마나 더 올라갈까

알레테이아가 화제를 모으는 동안, 제미나이 모델 패밀리도 존재감을 보이고 있다. 제미나이 3 프로와 플래시는 현재 프리뷰 버전으로 제공되고 있는데, 이 사전 출시 상태에서 이미 벤치마크 수치가 꽤 강하다.

제미나이 3 프로는 LMArena에서 Elo 1501로 전체 1위다. 클로드 오푸스 4.6과 GPT-5.2를 모두 앞선다. 전문 분야 벤치마크에서도 HLE(Humanity's Last Exam, 현재 AI로는 거의 풀기 어렵게 설계된 테스트) 37.5%, GPQA(대학원 수준 추론) 91.9%를 기록했다. API로 100만 토큰 컨텍스트 윈도우를 사용할 수 있어, 코드베이스 전체나 긴 논문을 한 번에 처리할 수 있다.

더 큰 반전은 제미나이 3 플래시에서 나왔다. 실제 소프트웨어 엔지니어링 벤치마크인 SWE-Bench에서 78%를 기록해 프로의 76.2%를 앞질렀다. 비싼 모델보다 싸고 빠른 모델이 코딩에서 더 나은 결과를 낸 셈이다. 가격도 100만 토큰당 입력 $0.50, 출력 $3으로 프로($2/$12)의 4분의 1 수준이다. 코딩 작업에서는 달러당 네 배의 효율인 셈이다.

제미나이 3 딥씽크는 전용 추론 모드로, HLE에서 41%(전 모델 최고 점수), ARC-AGI-2에서 45.1%를 기록했다. 세 모드를 합치면 쓸 만한 스택이 된다. 비용 효율이 필요하면 플래시, 범용 성능이 필요하면 프로, 깊은 추론이 필요하면 딥씽크.

흥미로운 건 이 모든 것이 아직 프리뷰 성능이라는 점이다. 구글의 로건 킬패트릭은 GA 출시 시 추가적인 성능 향상이 있을 것임을 암시한 바 있다. 커뮤니티 일부에서는 GA가 '3.5' 수준의 도약을 가져올 수 있다는 추측도 나온다. 실제로 그렇게 될지는 두고 봐야 하지만, 프리뷰만으로 이미 1위라는 건 나쁘지 않은 출발이다.

3. 제미나이 3.1 프로 프리뷰 포착: 현재가 나오기도 전에 다음이

그리고 예상 밖의 일이 있었다. 알레테이아 발표와 같은 날, 아티피셜 어낼리시스(Artificial Analysis) 아레나에 '제미나이 3.1 프로 프리뷰'가 등록된 것이다. 블로그 포스트도, 보도자료도 없었다. 그냥 모델이 조용히 공개 리더보드에 결과를 제출했을 뿐이다.

AI 커뮤니티는 바로 알아챘다. 레딧, X, 개발자 포럼에서 논의가 이어졌다. 핵심은 이거다. 3.0의 GA조차 아직인데 이미 3.1을 외부 테스트하고 있다면, 반복 속도가 꽤 빨라진 것이다. 이전 제미나이 버전 점프—1.5에서 2.0, 2.0에서 3.0—은 각각 수개월이 걸렸다. 이번에는 현재 세대가 정식 출시되기도 전에 다음 세대가 나타났다.

타이밍도 눈에 띈다. 앤트로픽이 일주일 전 클로드 오푸스 4.6을 출시했고, OpenAI도 GPT-5 시리즈를 계속 업데이트하고 있다. 알레테이아 발표와 같은 날 3.1 프리뷰를 내놓은 건, 딥마인드가 3.0 GA를 기다리며 쉴 생각은 없다는 뜻으로 읽힌다.

3.1이 실제로 어떤 성능을 가져올지는 아직 모른다. 코딩, 장문맥 안정성, 다국어 성능 개선에 대한 추측이 오가지만 확인된 건 없다. 확실한 건 2월 11일에 구글이 보여준 것이 꽤 많았다는 것이다. 3.0 GA 임박, 3.1 이미 테스트 중, 알레테이아는 범용 모델과 다른 접근—이게 다 같은 날이었다.

마치며

수학 난제를 자율적으로 풀어내는 에이전트, 프리뷰만으로 벤치마크 1위인 제미나이 3, 그리고 3.0 GA도 나오기 전에 슬쩍 모습을 드러낸 3.1 프리뷰. 이게 다 같은 날이었다.

딥마인드에게 바쁜 하루였다. 다음엔 뭘 들고 올지 궁금해진다.
