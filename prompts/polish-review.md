# GamerScroll Polish Review Rubric

Polish-quality review for a single Korean game-industry article in
GamerScroll/AIScroll JSON format.

Target schema: `title` / `summary` / `keywords` / `content[]` (text |
heading | image blocks) / `sources[]`. Review BOTH the meta fields and
the `content` array. Do NOT edit the file. Return findings only:
`인용 -> 지적 -> 수정안`. No praise, no overall summary, no "looks
good" sections.

Output language: Korean. Cap: <900 words total.

## 검증 우선순위 (위에서부터 치명도 높음)

### 1. 사실·번역 오류 (1순위)

- **영문 용어 오역** — 가장 자주 잡히는 함정:
  - `First-party` (자사/독점)를 `1인칭`(시점)으로 오역
  - `MMO`↔`ARPG`, `port`↔`release`, `port` vs `simultaneous release` 혼동
  - `acquisition`(인수)↔`merger`(합병) 혼용
- **본문 인용 매체 ↔ 링크 URL 도메인 불일치** — markdown 링크
  `[블룸버그](https://www.gematsu.com/…)`처럼 본문에서 명명한 매체와
  실제 링크 도메인이 다른 경우. 브래킷을 실제 매체명으로 바꾸거나
  URL을 본문 인용 매체의 기사로 교체.
- **발언자 매칭 오류** — 같은 회사의 다른 임원·전직 임원 발언을
  뒤섞는 케이스 (예: PlayStation 발언 인용 시 슈헤이 요시다 ↔
  숀 레이든 ↔ 짐 라이언 혼동). 출처 기사 원문에서 발언자 직책·
  성명을 한 번 더 확인.
- **IR / 재무 자료 해석 오류** — 누적·합산 수치를 단일 플랫폼·
  단일 기간 매출처럼 서술하는 케이스 (예: PS+PC 합산 누적
  2,000만 장을 "PC 합류로 두 배 됐다"고 해석). 출처 자료의
  집계 범위·기준일 확인.
- **게임명·인물명·스튜디오명 표기 오류** (Insomniac↔인섬니악 등)
- **발행 보도 시점 / 사내 발언 / IR 자료 등 1·2차 출처 구분 오류**

### 2. 수치·기간·고유명사 일관성

- 같은 글 안에서 숫자·날짜·기간 단위가 충돌하는 지점
  (예: "12주" vs "두 달" — 12주는 약 3개월)
- 약칭/풀네임 혼용 (예: "마블 토콘" vs "마블 토콘: 파이팅 소울즈")
- 영문/한글 표기 통일 (예: PlayStation vs 플레이스테이션)
- 통화·환율·연도 표기 일관성

### 3. SEO 점검

- `title` 길이: 한국 SERP 노출 한계 ~32자 안팎 초과 여부
- `summary`: 메타 디스크립션 ~150자 권장, 핵심 키워드 포함 여부
- `keywords` 필드의 토큰이 본문에 자연스럽게 노출되는지
- 첫 단락(`content[0]`) 100자 안에 핵심 키워드 1~2개 노출 여부
- 헤딩(type=heading) 블록에 키워드가 분산 배치되는지
- 이미지(type=image) `alt` 텍스트에 키워드·맥락 포함 여부

### 4. 헤딩-본문 정합성

- 헤딩이 다음 본문 블록의 논지를 정확히 예고하는가
- 본문 비중이 헤딩이 약속한 두 대상에 균형 잡혀 있는가
  (예: "A와 B가 증명할 시간" 헤딩 아래에 B만 다뤄지면 결함)
- 단어 선택이 본문 논지와 충돌하지 않는가
  (예: "착시" 헤딩인데 본문은 "트레이드오프"를 논함)

### 5. 톤·리듬·문체

- 반복 부사·접속어 (예: "사실상", "그러나"의 단락 내 중복)
- 자극적·옐로우 어휘 → 인사이트 매체 톤으로 정제
  (예: "못 박았다", "폭탄선언", "흘렸던")
- 작위 은유 → 담백 서술
  (예: "테이블 위에서 두드린 장기 계산기", "깎아낸 신작")
- 구어체 어미 → 정제 어미
  (예: "~거다", "~셈이다" → "~결과다", "~의미다")
- 단락별 호흡 (접속조사 중첩, 만연체)

### 6. 한국어 자연스러움

- 번역체 잔재 (피동 남발, 영어식 도치)
- 주어-서술어 호응 오류
  (예: "기네스가 등재했다" → "기네스북에 등재됐다")
- 조사 오류, 시제 비일관성
- 한자어 남발 vs 평이한 우리말 균형

## 출력 형식

```
### 1. 사실·번역 오류
* 인용: "..."
  지적: ...
  수정안: ...
```

각 항목당 결함 최대 3개. 결함이 없는 항목은 표시 생략.
